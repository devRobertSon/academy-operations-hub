# 에듀오케이 가져오기

## 확인된 범위

에듀오케이 공개 안내에는 학생정보와 수강이력 관리, 학생 자료의 엑셀 저장 기능이 표시되어 있습니다. 공개 API 규격은 확인되지 않았으므로 실제 연동 여부는 에듀오케이에 문의합니다.

## 업체 문의 항목

1. 학생, 반, 수강 이력과 시간표를 각각 CSV 또는 엑셀로 내보낼 수 있는지
2. 각 학생과 반에 변경되지 않는 고유번호가 있는지
3. 공식 API 또는 제휴용 연동 규격이 있는지
4. 변경된 자료만 조회하는 기능이나 웹훅이 있는지
5. 제3자 시스템으로 자료를 옮기는 것이 이용계약상 허용되는지

## 1차 가져오기 방식

1. 관리자가 에듀오케이에서 파일을 내려받습니다.
2. 포털의 `에듀오케이 가져오기`에서 CSV를 선택합니다.
3. 브라우저가 열을 인식하고 신규·변경·동일·오류로 구분합니다.
4. 관리자가 미리보기 차이를 확인합니다.
5. 서버 저장 기능이 연결된 뒤에만 가져오기를 확정합니다.
6. 확정 작업은 `importBatches`와 `auditLogs`에 남깁니다.

현재 구현은 4단계까지이며 Firebase에 쓰지 않습니다.

## 인식하는 열 이름

| 내부 항목 | 인식 후보 |
| --- | --- |
| 학생 식별번호 | 학생번호, 원생번호, 회원번호 |
| 학생명 | 학생명, 원생명, 이름, 성명 |
| 상태 | 상태, 재원상태, 학생상태 |
| 반 | 반명, 학급명, 수강반, 강좌명 |
| 학교 | 학교, 학교명 |
| 학년 | 학년 |
| 등록일 | 등록일, 입학일, 수강시작일 |

실제 에듀오케이 파일을 받으면 열 이름과 상태 값을 테스트에 추가합니다.

## 개인정보 안전

- 실제 CSV·XLSX 파일은 공개 저장소에 커밋하지 않습니다.
- 가져오기 파일은 필요한 열만 읽고 원본 전체를 Firestore에 보관하지 않습니다.
- 학생 고유번호가 없을 때 이름·학교·학년 조합은 미리보기 보조 기준으로만 사용합니다.
- 공식 API가 제공되어도 첫 단계는 읽기 전용으로 구성합니다.
- 에듀오케이 화면 자동 조작이나 크롤링은 업체의 명시적 허가 없이 사용하지 않습니다.
